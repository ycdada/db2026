## 已完成并提交的主要修复

当前修复已提交到：

- `HEAD e61700f 0.1`

主要修复内容：

- 保守复用 transaction 对象：只复用已完成、隐式、只读、非 MVCC、无写集合、无 MVCC 状态的 transaction。
- 增加 MVCC visible read overload，在 `mvcc_latch_` 下读取物理 record，并用于 seq scan、index scan、update、delete。
- GC 在 watermark 后清理已提交 delete tombstone，并物理删除 record。
- `UPDATE` / `DELETE` 写路径先获取 record exclusive lock，再重读 visible record 并重新检查谓词。
- `UPDATE` 仅在 index key 真正变化时删除并重插 index entry，避免非索引列更新时索引短暂消失。
- 隐式事务在向 client 返回 success response 前先 commit 并释放资源。
- `INSERT` write record 保存插入 record 内容。
- Transaction manager 跟踪未提交 physical insert RID owner：
  - `RegisterPhysicalInsert`
  - `UnregisterPhysicalInsert`
  - `OwnsPhysicalInsert`
- Abort/catch 路径只在 inserted physical RID 仍归当前事务所有时删除该 RID。
- Rollback inserted physical slot 后立即释放对应 record lock。
- `RmRecord` 默认初始化为 `nullptr/0`，避免未初始化状态。
